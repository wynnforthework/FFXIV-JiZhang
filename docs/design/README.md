# 金币账本 · Paper & Pine

本轮建立插件自己的暖纸白、墨绿、铜金视觉身份。仅借鉴 AutoFATEGrind 的托管字体、稳定命中区、可中断动效和减少动态效果处理；不再复用其紫色光晕、玻璃渐变卡片、窄图标侧栏组合。

- [可编辑 SVG 设计板](paper-pine.svg)：纯矢量图形和文字，可导入 Figma、Inkscape 等设计工具继续编辑。当前环境没有 Figma 连接，未声称已创建 Figma 云文件。
- [实际 ImGui 预览](preview.png)：来自插件共用的 LedgerView 原生 ImGui 绘制数据；使用示例数据，不是游戏内截图。
- [滚动状态](scrolled.png)：标题和按钮随卡片一起滚动，外层视口统一裁切。
- [空账本](empty.png)：无空白 Tooltip，无伪造账单。

## 视觉规范

背景 #F2F0E6、卡片 #FEFCF6、墨绿 #296457、铜金 #98632B。收入绿色、支出砖红；语义与数字正负号同时表达。顶部文字导航加下划线，细边平面卡片，正文 17px、标题与金额独立字号烘焙；禁止放大小字号字体纹理。

图表使用本月按日、当年按月、全部按月（超过十年按年）的统计。矩形树图面积对应金额，所有小分类均参与面积分配，过小矩形仅通过悬浮显示明细。趋势保留单边收支及量级差异显著时的独立刻度。

交互保留指数趋近、260ms 切页与280ms 可反向折叠。开启 Dalamud 减少动态效果时直接到终态。折叠后保留52px标题栏；独立滚动内容区与固定标题栏/底栏分离。

## 验证与限制

预览宿主使用微软雅黑；游戏内继续使用 Dalamud 托管默认字体，因此字形、系统缩放和游戏平台窗口仍需国服验收。静态 PNG 不证明动效；原生输入宿主另有213帧导航、周期选择、下拉、开关、折叠反向和关闭验证。

传送匹配新增“已接受请求 + 实际扣款金额 + 到达区域”三项关联。请求本身不生成账单，取消/免费传送没有余额变化时不入账，金额不匹配保留未分类。请求30秒过期；扣款与到达须处于2秒关联窗口，同一区域内无法独立确认到达时仍回退未分类。无需打开实验性窗口分类开关。既有未分类历史缺少证据，不据此批量改写。

本轮离线构建、核心测试和预览通过，国服传送钩子地址、实际减免费用、传送券及游戏内字体仍待实测。未通过实测前不发布正式订阅版本。
