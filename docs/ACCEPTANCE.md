# 国服验收与发布记录

## 已验证

- 本机国服 Dalamud 15.0.3.9 / .NET 10：Debug 与 Release 编译通过，零警告、零错误。
- 核心测试覆盖基线、连续变化守恒、早到／晚到证据、重复和冲突证据、同金额相邻交易、失败请求、角色隔离、记录中断、检查点、中文规则、转账统计、持久化、备份恢复和 CSV 公式转义。
- ZIP 白名单包含托管依赖和 Windows x64 SQLite 原生库，不包含 Dalamud 游戏引用。

## 0.1.1 界面修复验证

- 用户提供初版真实游戏界面截图，确认了标题栏对比度、布局和空白悬浮窗问题。
- 新版接入 WindowSystem / Window，主题在 PreDraw 阶段设置，确保标题栏和关闭按钮也使用正确配色。
- 使用同一份 LedgerView 与 LedgerTheme 运行原生 ImGui 离线渲染：空账本、有数据、空流水、流水、设置、760 像素窄窗口与 1.6 倍缩放。
- 空数据路径不创建图表交互项或 tooltip；有数据的非零日期显示深底白字的金额提示。
- 512、256、64 像素 AI 图标已制作，AI 使用情况已披露。
- 新版仍需在游戏中重新确认字体、窗口关闭/Esc、缩放和真实金币交易；离线渲染不能替代这些验收。

## 发布前逐项完成

- [ ] 本机开发插件成功加载；命令、插件管理器入口和卸载正常，无游戏错误。
- [ ] 首次加载只建立余额基线；重新登录、角色切换、重载后不串账。
- [ ] 支付传送费，记录金额、时间和出发地；免费传送／取消传送无流水。
- [ ] NPC 买入／卖出、市场成功购买（含税）与取消购买，核对金币与物品数量。
- [ ] NPC 修理、自修理、无费用修理分别检查；只记录实际金币变化。
- [ ] 任务和系统金币奖励记录正确，军票／诗学／金碟币奖励不入账。
- [ ] 玩家交易收入／支出／取消、雇员存取和部队存取正确；销售通知不重复计收入。
- [ ] 快速连续交易和切图的余额可对账；无法拆分或来源冲突时明确未分类。
- [ ] 实验识别关闭时全部正常金币变化仍入账，类别为未分类。
- [ ] 深色分层界面可读、中文无缺字、0.8–1.6 缩放、窄窗口和长列表可操作。
- [ ] 今日／本月／趋势／分类统计核对，转账排除选项有效，差额不计入普通统计。
- [ ] CSV 中文、时间和金额正确；备份、错误备份、恢复及重载后数据一致。
- [ ] 用待发包在独立开发插件目录验证依赖加载。
- [ ] 用本地测试清单指向待发 ZIP 验证自定义仓库安装／更新，正式清单只在发布后更新。
